# 静态插画质感与遮挡诊断

适用于用户强调“按原图质感复刻”、柔光与腮红，或选择带局部原画纹理的静态头像。它是制作选项，不是所有角色都必须采用的管线。需要换光、动画或实时导出时，先确认烘焙光影和透明发片是否适合用途。

## 1. 先分清差距来自哪里

将反馈落到原图中的具体关系，而不是笼统地“增加细节”：

- 形体：主发束方向、发旋位置、尖端长短、前后体积、眉形和耳廓。
- 材质：发色层次、亮暗块边缘、虹膜组织、腮红范围和过渡。
- 遮挡：眉线是否被刘海覆盖，耳朵露出多少，内层是否穿出外层。

先在同一取景下列出主要偏差并选择对应方法。等宽发片加纵向噪声、统一环形高光，通常不能替代原图中的发束组织。颜色和识别元素接近时，仍可能只是草模；用户继续指出缺失项说明验收应继续，不能将此前完成描述当成约束。

## 2. 选择材质表示

| 需要的结果 | 可用方法 | 必须说明或检查的边界 |
|---|---|---|
| 可随灯光变化的风格化角色 | 可编辑程序材质、绘制的基础色与几何细节 | 检查实际灯光响应；不要把新增虹膜或高光设计说成原图恢复 |
| 单图风格的静态展示 | 分束描线建曲面，再给各局部固定 UV，保留原画颜色细节 | 原图已有光影会随材质保留，正面相似不能证明侧后结构正确 |
| 原图没有的后发/侧发 | 人工补全几何，使用确认属于头发的局部纹理或另行补绘 | 记录推断区域；重复取样会暴露重复高光与分束，须看背面 |

可以混用，例如皮肤保留柔和灯光与程序腮红，头发和虹膜使用局部原画 UV。使用生成能力补绘纹理时另读图像生成技能并保留来源；不需要生成新图时直接使用已有参考，不增加不必要的依赖。

## 3. 局部 UV 的制作与排错

沿原图主束描左右边界，建立连续、有纵深的曲面，再按静态需求选择厚度、细分或发片。描线与人工深度不属于自动三维重建。细束和尖端的分离应由轮廓及必要几何承担，不能只有一块宽面承载整张发型。

描左右边界后，先确定同一截面上的对应点。齐刘海等以高度定义轮廓的区域，可按共同高度采样相邻边界；分别按两条曲线的归一化弧长配对，可能将不同高度连成一排，制造矩形露肤缺口或斜切边。保留参考所需的末端细缝，在不透明中性材质及正面、斜侧面下核对真实覆盖。

将 UV 固定到对应发束，转动相机时纹理应随表面运动。临时相机投影可帮助建立 UV，但不要让材质持续依赖当前观看方向，也不要把整张头像平面作为模型渲染。

检查每块表面实际取样的区域：

- 顶点 UV 落在发色内，并不保证面内取样安全。离散地把各点移到附近深色像素，面内插值仍可能穿过脸、眼睛或白底；检查整个 UV 面及插值路径。必要时建立沿发流连续的安全取样区域，并核对细分后的表面。收窄取样域会压缩或简化原画细节，应同时检查发丝比例并说明取舍。
- 后发不能盲目使用固定矩形；同一列像素在头顶可能是白底，在下方才是头发。
- 用 alpha 清除白底或浅色越界时，阈值只适用于已检查的参考。白发、浅金发和强高光可能被误删；需要时使用专门遮罩或修 UV/轮廓，不能推广某个 RGB 通道阈值。
- 单图局部 UV 的暗发案例中，正面肤色或白底取样只用于对应前向区域的透明遮罩或修剪，不能据此裁删环绕曲面的侧后面。颜色混合也要排除这些无效源像素；仅改最终 alpha 仍可能把白底混成灰色拖痕。遮罩需按实际取样区检查，不复制该案例的颜色通道阈值。
- alpha 能修纹理背景，不能修头壳穿插、后发穿到前层、或曲面之间的真实缝隙。多个透明层还要检查侧面、遮挡次序和当前渲染器的透明行为。
- 曲面边缘若直接穿过一个画在纹理上的主发束，会出现平头、重影或断线。调整分束边界、几何和 UV 的对应，不能仅用高光遮住。
- 眼睛与耳部也只能取各自局部区域。眼线、眉线若同时存在于纹理与新几何中，检查重复；插画中“透过头发可见的眉线”是风格折中，不是附着正确的证据。

## 4. 前后层、发根与头壳

先检查表面间距，再调材质：

| 症状 | 常见候选原因 | 对应处理 |
|---|---|---|
| 正面突然出现不同色块 | 后发越过前发；原图取样越界 | 隔离前后层，检查实际深度和 UV，修责任对象 |
| 细密拉链纹或闪烁 | 相邻曲面近乎共面、深度冲突 | 调整实际层间距与各束弧度，不靠材质噪声掩盖 |
| 侧额小块露皮 | 内层未覆盖头壳，或 alpha 删除了应保留的像素 | 去纹理/隔离检查，必要时按相机射线定位命中对象 |
| 补缝后额前出现帽沿、直边或齿状边 | 内层过大，结束位置压到应露肤的区域 | 仅修局部覆盖与发际线，不整圈放大或下移 |
| 侧面发束突然折弯 | 分段深度函数位置或斜率不连续 | 平滑体积过渡，同步检查附属细线、厚度和相邻层 |

射线定位方法见 [执行可靠性](blender-reliability.md#露色和穿插从可见像素定位几何)。扩大内层之前检查头壳、发根和前束的求值表面；发根中心线在外侧不代表整个截面都在外侧。

参数化头顶出现中央破洞、重复发缝或星形拉伸时，分别检查极点拓扑、相交根部和 UV。环形曲面闭合顶端时，可整理为共享极点的连续顶冠，避免多组根部各自收拢成重叠的退化顶环；保留仍承担遮挡的内层。顶冠与下方发束使用同一固定坐标基准衔接发流，取样域须排除额头和背景。顶视彩色图验证发流，中性材质的顶视、斜俯和侧面验证闭合及接口。齐切根边若浮在顶冠外，会形成帽沿；可在局部连接带调整真实层间距和曲率，让上下边缘分别藏入邻层，再检查穿插与轮廓。中央错误消失不等于所有接口均已无缝。

## 5. 柔光、腮红与小五官

皮肤的柔和明暗、基础色和腮红应可独立调整。将红晕绑定到最终表面坐标或 UV，用连续渐变控制范围，近景和斜侧面都应保持贴合。淡纹理、鼻尖和唇部小高光按参考添加；薄的表面标记不应变成侧面凸刺。

混用自发光风格化着色、实体着色和灯光时，先固定色彩管理、曝光和世界照明，以少量实体贡献试渲染。过曝会冲淡腮红与高光，先找过亮来源，不要继续加深红色补偿。灯光功率、混合比例和肤色参数取决于模型尺度与场景，不复制某次成功数值。

眉毛按原图建立弧度与粗细变化，并检查眉尾与刘海的关系。耳部按可见程度制作耳根、外缘、凹入耳窝、耳垂及必要内耳脊；贴图中的暗色不等于真实凹陷。需要灰模和斜侧面来确认附着与体积。

## 6. 交付前分开看三种结果

- 彩色固定相机对照：判断发流、材质、眉眼、耳部与腮红是否更接近主参考。
- 隐藏头发的脸部灰模：判断眉耳、眼面与脸部体积。全材质覆盖会移除画入纹理的眼线等细节，说明检查目的。
- 头发中性材质：去掉原画色彩与烘焙明暗；发片可保留 alpha 查看实际可见边界，必要时再关闭 alpha 检查底层网格，明确两者区别。

最后重开并验证资源与改动范围。报告分别说明哪些改善来自几何、哪些来自原画纹理、哪些侧后区域是推断。没有侧面参考时，不给侧面编造相似度指标；灰模、有限坐标或文件哈希都不能替代外形判断。

## 7. 发质修正闭环

每轮将原图与当前固定相机渲染对照，选出影响最大的具体差异，写明候选原因、验证方法和应保留的特征。保留可用基线；试验另存，实际看图后决定采用或否定。后续修正从已采用基线开始，不能默认编号最新就是最佳版本。标清“尚未试验”，避免把准备实施的方法写成成功经验。

### 接缝、重影与取样边界

- 先给疑似相邻部件临时分配不同纯色，并保留原来的透明遮罩，定位可见直边归属；必要时再关闭遮罩或使用射线。直边可能来自前发片的侧边，而不是看起来贴近它的侧发根部。诊断场景不覆盖制作工程。
- 多张独立生成的前、侧、背纹理可能画了不同的主束。颜色交叉混合会出现双线、高光重影；改成硬切又会产生色块。优先统一曲面边界、发束设计与固定 UV，可用统一图集承载连续区域；图集本身不保证接缝消失。不要让材质随观察方向切换发流来掩盖不一致。
- 透明度渐变只能弱化边缘。两层各自有描线时，渐变区仍会混合两套发流；结构边界仍切断主束时，应调整边界和对应纹理。检查正面轮廓与斜侧面，不能仅凭直边变淡就认定修复。
- 核查图片通道及实际像素：画入 RGB 的棋盘格不是 alpha。降低背景剔除阈值可能把棋盘格或白底显露为脸上的白斑；同时留意浅紫高光和白毛被误删。阈值只适用于已检查的取样区域。
- 编辑或生成 UV 图集后，逐块检查轮廓、面部空洞、边缘留白与原 UV 是否仍对齐。生成结果可能改变刘海外形，即使风格相近，也会出现白边、黑边或越界取样。只采用配准合格的区域，其余保留原纹理或重新配准。

### 发束与局部毛流

- 长发沿束长方向建立 UV，检查宽度、截面和纹理方向。纵向细线能增加表面细节，却不能修复等宽帘状主束、重复尾钩和不合理空隙；不要用更密线条替代主束组织。
- 内层大缝优先检查束中心线与相邻层关系。若意图只是收拢束群，避免直接缩放全部顶点而把束截面压成细绳。尾部修形分别控制中心线曲率与截面收尖，保留宽度和长短层次；统一拉直所有尾部可能变成一排尖刺。附属描边和高光随同变形。
- 耳毛和长发的毛流不同。少量三角面上直接复用纵向长发 UV，可能产生斜条与硬折纸感；隐藏杂线也不能补足毛簇体积。对照耳廓、耳窝、白毛覆盖和方向，决定是否需要局部纹理与曲面重建。局部原画 UV 仍需检查侧向厚度，不能只凭正面贴图验收。
