# 手艺

## 模板结构

`assets/film-template.html` 从上到下：

| 区块 | 作用 |
|---|---|
| 时间工具 | `K` 关键帧、`seg`、`ss`、`sseg`、`lerp`、`mulberry` 伪随机 |
| RENDERER AND POST | HalfFloat 渲染目标、景深、暗角、高光过渡、sRGB、颗粒。一般不用改 |
| FACES | `drawFace` 在画布上画表情，参数见 `FACES` 对象 |
| CHARACTER | `makeCharacter` 和 `pose()` |
| WORLD HELPERS | `put` `phys` `blob` `grainTex` `tile` `bakeEnv` |
| WORLD | **换成这部片的世界** |
| PERFORMANCE | **角色的动作轨道** |
| SHOTS | **镜头表**，`[开始时间, (t, u, h) => ({ p, l, f, focus })]` |
| update | 每帧把上面的状态写进场景 |
| offline | 多次采样累加。`window.renderFrame` 只给脚本用 |
| SOUND | **声音**，和画面用同一条时间轴 |
| player | 网页播放器 |

全程保持纯函数：同一个 `t` 必须得到同一帧。不要用 `Date.now`、`Math.random`，也不要累积状态，否则多采样和拖动进度都会出错。随机用 `mulberry(seed)`。

## 世界

**角色先定颜色，再定场景。** 主角要和所有道具分得开。橙色主角旁边的橙色积木会让它消失，换成蓝色马上就好。

**尺度决定质感。** 把角色当成 5 厘米高的玩具，书、铅笔、杯子都按真实比例放大，配合浅景深，立刻有微缩摄影的感觉。

**表面要有细节。** 大色块最显假。用 `grainTex` 做木纹，画布上写字迹，地面印上淡淡的文字。细节放在焦点附近，远处交给虚化。

**文字做成实物。** 用 `tile` 把词做成带清漆的积木，字印在正面。低机位看不清顶面，所以字要朝向镜头。不同类别用柔和的不同颜色，读起来就像语法高亮。

**背景要弱。** 背景物体亮度压到 15% 到 30%，放远，靠虚化变成色块。背景又亮又清楚时，全片都显得碎。

**接触阴影不能省。** 每个落地的物体都放一个 `blob`。没有它，物体看起来是飘着的。

## 灯光

至少四层：主光（带阴影）、半球环境光、冷色轮廓光、暖色正面补光，再加烘好的环境反射 `bakeEnv`。

- 主角背光时脸会发灰发紫，加一盏从镜头方向来的暖光。
- 每个场景一种主色调。切 `scene.environment` 和灯光颜色就够了。
- 多采样时在 `update(t, s)` 里用 `s` 抖动光源位置，就能得到真实的软阴影。
- 自发光和绿光容易过曝。发光材质的 emissive 从 0.1 到 0.2 试起。
- 光晕用平滑衰减的贴图，普通 `softDot` 放大后会露出硬边。

## 镜头

- 一场至少两种景别，全景交代、特写抒情。表情戏放在中近景。
- 角色走路是侧面，脸看不到。需要看表情时让它转向镜头，或者把机位放到它前方 30 度。
- 关键起因要用特写。偷分号放在全景里没人看得清，放到特写后故事才成立。
- 角色跳起时提前留出头顶空间，否则会出画。
- 用 `focus` 做焦点转移，从前景转到远处是最便宜的电影感。
- 特写时检查前景有没有挡住嘴。角色的表情大半在脸的下半部分。

## 声音

- 脚步从走路相位算出来，音乐可以跟同一个节奏，这样画面慢，声音也慢。
- 音乐走 `ML/MR` 总线获得房间感，音效直接走 `L/R`。
- 一段彻底的静音比任何音乐都有力。在 master 处乘一个能到 0 的窗口。
- 循环片的房间底噪要首尾交叉淡化，模板已经做好。
- 片子整体偏轻时，改 `tanh` 前的增益，再让 `norm` 归一化。

## 踩过的坑

- **同一平面的两个面会闪烁。** 让薄板比基准面突出或缩进一点点。
- **`hidden` 属性被 CSS 盖掉。** 给有 `display` 的元素写 `.x[hidden] { display: none; }`，否则载入文字一直盖在画面上。
- **按行号抽取代码。** 文件改一行就错位，要用文本标记定位。
- **8 位累加会出色带。** 模板用 HalfFloat 累加，别改回 canvas `drawImage`。
- **颗粒吃码率。** 全帧颗粒让 CRF 15 暴涨到 43 Mbps。用 CRF 17，不要用 CRF 20 压成片。
- **Artifact 上传视频可能超时。** 14 MB 和 9 MB 都失败过。MP4 直接发给用户，别反复重试。
- **`ffmpeg -ss .9` 会报错。** 时间要写成 `0.9`。部分 ffmpeg 没有 `drawtext`，拼图不要依赖它。
- **角色转身的角度。** `K` 按数值插值，不知道角度是周期的，跨越 2π 时会绕远路。同一段轨道里用连续的角度值。
- **分段后的局部时间。** 在 `t` 上平移的片段，别把 `DUR` 和局部结束时间混用，淡出和灯光都会错。
