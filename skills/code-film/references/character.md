# 角色定稿

默认主角是 Clawd，不需要走这一页的设计流程。这一页用于用户明确要新角色的时候，以及确认已有角色的细节。

角色是片子的核心。同一套渲染，好角色能撑起全片，几何体拼出来的角色再怎么打光也不好看。所以角色单独做、单独确认，通过后才写故事。

## 设计原则

**先定轮廓。** 把角色涂黑还能认出来，才算有设计。小芽是“梨形 + 两片叶子”，Clawd 是“圆角方块 + 小手”。不要用方块和球直接拼。

**用曲面造身体。** 用 `LatheGeometry` 沿一条样条旋转，比缩放过的球或圆角盒有型得多。身体上加一层竖向渐变贴图，比单色有厚度。

**幼态比例讨人喜欢。** 头大身小，眼睛大、靠下、间距宽，嘴小且贴近眼睛，四肢短。想要成熟或搞笑的气质时，有意打破它。

**一个记忆点，一个配色重点。** 小芽的红围巾和主体的黄色形成对比。全身不超过三种主色，一种重点色。

**一个会演戏的部件。** 让脸以外的部位也能表达情绪：小芽的叶子开心时竖起，难过时耷拉。这个部件也负责跟随晃动，让动作显得柔软。

**脸贴在身体上。** 用同一曲面切出一片当脸，表情随身体转动，比平面贴片自然。

**配角用同一套语言。** 同样的材质和眼睛画法。第一版小虫丑，就是因为它和主角不是一个世界的东西。

## 角色文件

角色是一个独立的 JS 文件，放在影片文件夹里，以后可以反复使用。写新角色时，以 `assets/characters/sprout.js` 为起点改造，不要从零写。

约定：

- `makeCharacter()` 返回 `{ root, pose(p, tt) }`。
- `EXPRESSIONS` 是“名称到表情对象”的映射，至少 8 种：平静、开心、惊讶、难过、无语、生气、害羞、感动。
- `pose` 读这些字段：`x y z ry rx rz scale sq breath lean armL armR hug reach walk stride leaf flutter face`，不认识的字段直接忽略。

已有角色：`clawd.js`（默认主角，两只脚，不能删除或替换）、`sprout.js`（原创，用户要新角色时的备选和起点）。

## 出定稿图

```bash
uv run --with playwright --python 3.12 python -I <skill-dir>/scripts/character_sheet.py <character.js> <outdir>
```

生成三样东西：

- `turnaround.jpg`：正面、四分之三、侧面、背面。
- `expressions.jpg`：8 种表情。
- `walk.mp4`：走路、停下、高兴、跳、挥手，7 秒。

调外形时加 `--no-walk`，省时间。用 Read 看图片，从 `walk.mp4` 抽几帧检查动作。

背景固定为中性灰，这样不同角色可以比较，也不会靠环境色掩盖问题。

## 自查清单

- 轮廓一眼能认，四个角度都成立。
- 脸没有被任何部件挡住。
- 8 种表情盖住名字也能分清。
- 走路时左右脚交替，身体有摇摆；跳起时拉长，落地时压扁。
- 动起来时有部件在跟随晃动。
- 和上一部的角色放在一起，质量不低。

## 确认

把三样东西发给用户，明确请他们确认。通过后才写故事，再用下面的命令放进影片：

```bash
python3 <skill-dir>/scripts/use_character.py <character.js> <film.html>
```

用户已有角色时，跳过设计，但仍然出一次定稿图，确认脚数、比例这些细节。上次 Clawd 被做成四只脚，就是做到样片才发现。
