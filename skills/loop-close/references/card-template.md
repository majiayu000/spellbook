# 功能卡模板

开工前填，放在 `docs/loop/<事项名>.md` 顶部。后面七步在同一个文件里往下追加。

```
事项：
类型：新能力 / 体验修复 / 底座建设 / 分发触达 / Skill 与内容 / 探索实验 / 调研
支撑什么：推动哪个指标（或支撑哪个决定）
假设：如果做了 X，Y 类人会 Z
主指标：        基线：        目标：        观察窗口：
护栏指标：（不能变差的，比如失败率、退款率、成本）
失败判定：到 ___ 时如果 ___，就停掉或改方向
目标使用者与一个真实任务：
不做什么：
负责人：
状态：定目标 / 实现中 / 验收中 / 观察中 / 已复盘
```

调研类把"主指标"换成"要支撑的决定"，把"失败判定"换成"什么证据会让我放弃这个方向"。
