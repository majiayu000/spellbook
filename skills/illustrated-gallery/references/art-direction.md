# Directions for original illustrated websites

Use these examples to explore a suitable direction, not to select a rigid theme.
Mix qualities when useful. Keep each project's actual subject and user task in view.
No direction requires a specific image, image count, palette, or animation.

| Direction | Visual language | Possible subjects | Page composition |
| --- | --- | --- | --- |
| Editorial field notes | Warm paper, ink, one strong accent; serif display type with clear sans-serif body | Maps, objects, spatial metaphors tied to the topic | An illustrated opening, numbered features, marginal labels, dense readable index |
| Material laboratory | Charcoal or chalk, ceramic, glass, metal; controlled studio light | Routing tracks, calibration instruments, modular assemblies | Split image and copy, process studies, compact resource rows, contrasting reading area |
| Graphic print studio | Flat shapes, limited bold colors, halftone or cut-paper texture | Symbols and scenes derived from the product's purpose | Asymmetric posters, generous labels, modular sections, clear navigation |
| Quiet photographic archive | Natural light, restrained color, documentary textures | Actual user assets or clearly conceptual still-life scenes | Image-led chapters, small captions, wide whitespace, restrained typography |
| Computational exhibition | Monochrome with a selective accent, precise line work, measured rhythm | Spatial networks, fields, topology, meaningful abstract structures | Large diagrams or artwork, compact annotations, structured reading and discovery sections |
| Expressive illustrated journal | Ink, gouache, pencil, or mixed-media marks with human texture | Project-specific stories, places, objects, or processes | Varied image scales, editorial columns, chapter dividers, legible supporting text |

## Turning a direction into prompts

Begin with the section's role. For a routing library, an architectural branching
track could express choices; for an archive, a layered collection of objects may
express discovery. Those are examples of reasoning, not reusable default subjects.

Select a medium and consistent material or color relationships. Specify where
copy will sit, which detail must remain visible on mobile, and what the image must
not imply. Keep actual labels and controls in HTML. Use the available generation
tool, inspect its output, and revise the prompt based on what the image needs.

Avoid superficial variations: the same image recolored into several palettes is
not several visual directions. A direction should change composition, texture,
type relationships, and the way the content is organized, not merely hue.

## Extending the direction below the hero

- Discovery pages: group entry points by use case, distinguish selected material
  from the full index, and keep search, category state, and empty results clear.
- Learning pages: use chapter rhythm, annotated illustrations, and readable steps.
- Portfolios: vary work-image scale and connect each image to a real project.
- Product pages: show the workflow and useful evidence without fabricated metrics.

Create enough visual variation to guide reading without making every section a
new theme. Art direction must improve the main content, not displace it.
