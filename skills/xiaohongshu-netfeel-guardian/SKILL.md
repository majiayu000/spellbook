# 小红书/内容网感守护者

帮助个人内容创作者对抗 Claude 常见的“英文思考”污染，输出真正有情绪、有网感的中文内容。

## 核心问题（PAIN-301 实证）
Claude 在复杂内容生成任务中容易回退到英文思维链，导致：
- 句式僵硬（“亲爱的朋友们，你们能理解这种感受吗”）
- 文化框架西化（美剧梗、In conclusion、西方线性逻辑）
- 情绪稀释
- 长内容中途失效概率大幅上升

社区共识：Claude 适合做框架，**网感需要额外守护**。

## 工作流程

1. **接收原始输出或生成请求**
2. **CoT 语言检测**
   - 扫描中间思考痕迹（即使最终输出是中文）
   - 标记英文句式、文化假设、逻辑框架
3. **网感重写**
   - 强制纯中文思维链重构
   - 注入真实高赞小红书/公众号语料（情绪、口语化、平台禁忌）
   - 按平台适配语气（小红书种草 vs 公众号深度 vs 视频脚本）
4. **多版本输出 + 自检**
   - 提供 2-3 个不同情绪强度的版本
   - 最后自检是否还有翻译腔 / 西方框架
5. **可选**：生成“反英文思考”系统提示片段，供用户持久化到 CLAUDE.md

## 与现有技能的组合方式（推荐）

最强工作流：
1. 用 `xiaohongshu` 做框架 + 结构 + 平台约束
2. 把输出喂给本技能做**网感守护 + 反英文思考重写**
3. 可再接 `humanizer` 做最终去AI味打磨

## 注意事项（Safety Contract）

- 仅修改语言和文化表达，不改变用户原本想表达的核心观点
- 尊重用户在 CLAUDE.md / AGENTS.md 里设定的人设和语气
- 提供多个版本供用户选择，而不是强行替换
- 所有修改必须可追溯（给出改动前后的对比）

## 局限说明

本技能不会凭空创造“网感”，它依赖：
- 用户提供的真实高赞语料（推荐定期补充）
- 用户自己的人设设定

它最擅长的是**防止 Claude 把本来有网感的内容翻译成没网感的内容**。

## 评估建议（主观类 Skill）

因为“网感”高度主观，建议采用：
- 人工盲测（推荐 70% 权重）：找 5-10 篇真实爆款笔记做参考，让人盲测“哪篇更像真人写的”
- 轻量自动化 proxy（30% 权重）：检测特定翻译腔句式出现率、西方文化假设密度
- 真实世界验证：实际发帖看数据（收藏/评论/完播率）

避免过度复杂的 evals 导致“技能坟墓”。
